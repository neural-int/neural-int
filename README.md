## What I'm building

### [commiter-cli](https://github.com/neural-int/commiter-cli)

A developer CLI that analyzes Git changes and helps turn them into well-structured commits.

The project focuses on keeping deterministic preprocessing in code and using LLMs only where semantic judgment is useful.

### PostPilot

An Instagram publishing and scheduling application built around the Meta Graph API.

It includes a React Native client and backend services for authentication, media handling, scheduled publishing, and automation.
